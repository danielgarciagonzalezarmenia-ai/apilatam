Documentacion de la API

Guia completa para integrar la API de canales TV y peliculas en tu proyecto.

Como Funciona

La API se consume directamente desde el navegador usando el SDK de Firebase. No necesitas servidores ni configuracion compleja.

Obtienes tu API key desde el dashboard y la usas para autenticar tus peticiones.

Instalacion

Importa el modulo de la API en tu proyecto JavaScript:

// En tu HTML
<script type="module">
  import { getChannels, getMovies } from 'https://TU_DOMINIO/js/api.js';
</script>

Funciones Disponibles

FUNCION getChannels(apiKey, category?)

Obtiene la lista de canales de TV disponibles.

Parametros:

  • apiKey (requerido) - Tu API key
  • category (opcional) - Filtrar por categoria

Respuesta:

{
  "channels": [
    {
      "id": "abc123",
      "name": "ESPN",
      "imageUrl": "https://...",
      "m3u8Url": "https://...",
      "category": "Deportes"
    }
  ],
  "total": 5,
  "plan": "free"
}
FUNCION getChannelById(apiKey, id)

Obtiene los detalles de un canal especifico por su ID.

FUNCION getMovies(apiKey, category?)

Obtiene la lista de peliculas disponibles.

Parametros:

  • apiKey (requerido) - Tu API key
  • category (opcional) - Filtrar por categoria
FUNCION getMovieById(apiKey, id)

Obtiene los detalles de una pelicula especifica por su ID.

FUNCION getCategories(apiKey)

Obtiene todas las categorias disponibles.

Ejemplos de Codigo

JavaScript (navegador)

import { getChannels, getMovies } from 'https://tu-dominio/js/api.js';

// Obtener todos los canales
const canales = await getChannels('aplat_TU_API_KEY');
console.log(canales.channels);

// Filtrar por categoria
const deportes = await getChannels('aplat_TU_API_KEY', 'Deportes');
console.log(deportes.channels);

// Obtener peliculas
const peliculas = await getMovies('aplat_TU_API_KEY');
console.log(peliculas.movies);

HTML simple

<script type="module">
  import { getChannels } from './js/api.js?v=4';

  const data = await getChannels('aplat_TU_API_KEY');
  document.getElementById('app').innerHTML =
    data.channels.map(c =>
      `<div><img src="${c.imageUrl}"> ${c.name}</div>`
    ).join('');
</script>
