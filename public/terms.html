2. Descripcion del Servicio

API LATAM proporciona una API REST para acceder a contenido de canales de television en vivo y peliculas. El servicio incluye:

  • Acceso a endpoints REST con respuestas en formato JSON.
  • Autenticacion mediante API keys.
  • Planes de acceso gratuito y de pago.

3. Cuentas de Usuario

Para utilizar el servicio debes crear una cuenta a traves de Google Authentication. Eres responsable de:

  • Mantener la confidencialidad de tu API key.

  • Sobrecargar la infraestructura con peticiones automatizadas excesivas.
  • Revender el acceso a la API sin autorizacion.
